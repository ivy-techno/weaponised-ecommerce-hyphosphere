- the agent-mediated current-signal feed, including pause/resume, HTTPS citations, relevance labels, and selective notebook capture.

The latest application-feature commit before submission documentation is `660da42` (`Add agent mediated signal feed`, 4 September 2026). The full commit history provides timestamped evidence of iterative implementation.

## Important scope boundary

Hyphosphere includes a deterministic demonstration corpus and a curated index of external sources. It does not claim that every linked external record has been imported or independently verified. Current web material can be researched by a connected agent and supplied to the page through `publish_signal_feed`; the page itself is not represented as an autonomous crawler.

The larger Observatory—production ingestion, authenticated private collections, collaborative persistence, and a substantially expanded case-study database—remains future work.
